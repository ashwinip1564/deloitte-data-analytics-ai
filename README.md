## Project 1: Daikibo Telemetry Analysis

*Objective:* Analyze industrial telemetry data to investigate equipment downtime across factories and device types.

*Tools:* Tableau, data visualization, calculated fields

*Work performed:*
- Imported and explored industrial telemetry data.
- Created an Unhealthy calculated measure, assigning a value of 10 to records with an unhealthy status.
- Developed downtime visualizations by factory and device type.
- Configured the factory downtime chart as a dashboard filter to support interactive analysis.
- Examined the results to identify factories and equipment categories associated with downtime.

*Deliverables:* Tableau dashboard screenshots and documentation of the analysis workflow.
